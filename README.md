# ☸️ Kube 101 Documentation

### Kubernetes concepts — from fundamentals to interview ready

Welcome to **Kube 101 Documentation** — a practical Kubernetes learning repository created to help **freshers, aspiring DevOps engineers, and experienced professionals** strengthen their Kubernetes knowledge and prepare for **DevOps/SRE technical interviews**.

The goal of this repository is simple:

> **Understand the fundamentals → Learn how Kubernetes works → Solve real-world scenarios → Become interview ready.**

## 🎯 Purpose of This Repository

Kubernetes can initially feel overwhelming because there are many concepts, components, and commands to learn.

This repository aims to make that journey structured and easier to follow by covering Kubernetes **from the fundamentals to production-oriented and interview-focused scenarios**.

The content is designed to help you:

* 📚 Build a strong foundation in Kubernetes
* 🔍 Understand how Kubernetes components work together
* ⚙️ Learn concepts from a practical DevOps/SRE perspective
* 🐛 Develop troubleshooting and problem-solving skills
* ☁️ Understand Kubernetes in cloud environments such as AWS EKS
* 💼 Prepare for DevOps/SRE/Kubernetes technical interviews
* 🎯 Progress from beginner-level concepts to real-world scenarios

## 🧠 How to Use This Repository

You don't need to go through everything at once.

A recommended approach is:

```text
1. Learn the concept
       ↓
2. Understand why it is required
       ↓
3. Understand how it works
       ↓
4. Look at a real-world example
       ↓
5. Try the commands
       ↓
6. Solve the troubleshooting scenario
       ↓
7. Attempt the interview question
```

The goal is to move beyond **"I know the definition"** to:

> **"I understand how it works and I know how to troubleshoot it."**
